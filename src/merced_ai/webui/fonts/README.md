Self-hosted web fonts for the local UI, so the layout does not depend on what the user has
installed. Both are Latin-subset variable woff2 files from Fontsource 5.3.0, under the SIL Open
Font License 1.1 (license texts alongside).

| File | Family | Source |
|---|---|---|
| `inter-latin-wght-normal.woff2` | Inter (variable weight) | `@fontsource-variable/inter` |
| `source-serif-4-latin-wght-normal.woff2` | Source Serif 4 (variable weight) | `@fontsource-variable/source-serif-4` |
